## **Система и продукт**

**VK HR Tek** — сервис кадрового электронного документооборота (КЭДО) — единая модульная платформа с набором готовых сервисов.

**КЭДО** — Кадровый Электронный Документооборот — безбумажный обмен кадровыми документами на единой платформе VK HR Tek.

**Личный кабинет** — персональное рабочее пространство сотрудника в VK HR Tek.

**Кабинет компании** — рабочее пространство представителей компании (руководителей, HR-специалистов и др.) для управления процессами.

**Веб-сервис / Веб-интерфейс** — браузерная версия VK HR Tek.

**Мобильное приложение** — мобильная версия сервиса VK HR Tek, которую можно установить и обновить через магазин приложений для мобильных устройств.

**Адаптивная версия** — мобильная версия веб\-интерфейса, адаптированная под экраны смартфонов.

**Аккаунт** — объединение нескольких юридических лиц в холдинг или группу компаний для централизованного управления настройками.

**Юрлицо / Юридическое лицо** — отдельная компания в рамках сервиса.

**Портал** — модуль социальных сервисов VK HR Tek (Новости, Сообщества, Опросы).

## **Пользователи и роли**

**Сотрудник** — базовая роль пользователя системы; каждый подключенный к системе пользователь получает эту роль по умолчанию.

**Руководитель** — сотрудник, имеющий подчинённых и права на согласование их заявок.

**Администратор** — системная роль с максимальными правами: управление настройками компании, типами заявок, ролями, шаблонами документов, типами электронных подписей.

**Отдел кадров / Специалист кадровой службы** — функциональная роль сотрудника, отвечающего за кадровые процессы.

**Профили доступа** — механизм ограничения доступа сотрудников к данным (заявкам, сотрудникам) в рамках выданной роли.

**Системные роли** — предопределённые роли с фиксированным набором действий: Сотрудник, Администратор, Рекрутер, Менеджер графика отпусков, Редактор МЧД и др.

**Функциональные роли** — роли, настраиваемые под бизнес-процессы компании (Отдел кадров, Бухгалтерия, Менеджер тревел-отдела).

**Родительская роль** — вышестоящая роль по иерархии; пользователь с родительской ролью видит все заявки подчинённой роли.

**Представитель компании** — сотрудник с ролью, отличной от базовой «Сотрудник» (руководители, HR, администраторы).

**Заместитель** — сотрудник, назначенный выполнять действия руководителя по заявкам (постоянный или временный).

**Ассистент подразделения** — сотрудник, помогающий руководителю подразделения в согласовании заявок.

**Рекрутер** — системная роль для работы с кандидатами.

**Менеджер графика отпусков** — системная роль для управления графиками отпусков.

**Редактор МЧД**	 — системная роль для управления машиночитаемыми доверенностями.

**Администратор главной страницы** — системная роль для управления виджетами и навигацией на главной странице сервиса.

## **Организационная структура**

**Организационная структура / Оргструктура** — иерархическая структура подразделений и должностей компании.

**Штатное расписание** — документ со оргструктурой, штатным составом и численностью организации.

**Штатная позиция** — конкретная должность в штатном расписании с определённым количеством ставок.

**Бейдж** — метка на карточке сотрудника/заявки с дополнительной информацией.

## **Бизнес-процессы и заявки**

**Бизнес-процесс (БП)** — последовательность этапов обработки кадрового документа (заявки).

**Тип заявки** — конкретный вид бизнес-процесса (Отпуск, Командировка, Кадровый перевод и др.).

**Универсальный процесс** — БП, созданный администратором под индивидуальные нужды компании.

**Преднастроенный процесс** — готовый БП из стандартного списка VK HR Tek.

**Заявка** — электронный документ, проходящий цепочку этапов в рамках БП.

**Этап заявки** — отдельный шаг БП: создание, согласование, подписание, загрузка, проверка.

**Цепочка согласований** — последовательность руководителей, согласующих заявку.

**Маршрут подписания** — порядок подписания: сотрудником, компанией или в смешанном порядке.

**Исполнитель этапа** —	роль, ответственная за действия на конкретном этапе.

**Валидатор** — правило проверки данных в заявке.

**Дедлайн** — ограничение по времени для подписания/проверки; по истечении указанного срока заявка автоматически отменяется.

**Атрибут (заявки)** — поле в заявке (Дата начала отпуска, Дата перевода и др.).

**Справочник** —	тип атрибута — список предопределённых значений.

**Маппинг** — сопоставление документов БП с документами в 1С.

**Листинг заявок** — список заявок с фильтрацией, сортировкой и поиском.

**Карточка заявки** — страница с детальной информацией о заявке.

**Шапка заявки** — верхняя часть карточки с ключевыми атрибутами и статусом.

**Пакет документов** —	набор документов, подписываемых в одной заявке. 

## **Документы и подписание**

**Шаблон документа** — форма документа с плейсхолдерами для автозаполнения.

**Плейсхолдер**	— поле шаблона, заменяемое на статические данные для сотрудника (напр. {{ .Employee.LegalUnits.Up1 }}), компании, пользователя, инициатора, документа, или на динамические данные для конкретной заявки.

**Печатная форма** — сформированный по шаблону документ, готовый к подписанию.

## **Электронная подпись**

**Электронная подпись (ЭП)** — цифровой аналог собственноручной подписи.

**УНЭП** — Усиленная Неквалифицированная Электронная Подпись — выпускается в сервисе VK HR Tek.

**УКЭП** — Усиленная Квалифицированная Электронная Подпись — требует сертификат от УЦ.

**УЦ (Удостоверяющий центр)** — организация, выпускающая сертификаты ЭП (например, УЦ Контур).

**СМЭВ** — Система Межведомственного Электронного Взаимодействия — проверяет данные сотрудника при выпуске УНЭП.

**ЕСИА** — Единая Система Идентификации и Аутентификации (Госуслуги) — для подтверждения личности.

**Сертификат (ЭП)** — документ, подтверждающий принадлежность ключа ЭП владельцу.

**Открытый ключ** — криптографический ключ сертификата для проверки подписи.

**МЧД** — Машиночитаемая Доверенность — подтверждает полномочия действовать от имени организации.

**Токен**	— уникальный код для интеграции с 1С (срок действия — 90 дней).

**Перевыпуск УНЭП** — повторная процедура выпуска электронной подписи.

**Валидация СМЭВ по типам ошибок**	— настройка, определяющая поведение сервиса VK HR Tek при ошибках проверки СМЭВ.

## **Корпоративные документы (ЛНА)**

**ЛНА** —	Локальный Нормативный Акт — документ, обязательный для ознакомления сотрудниками.

**Корпоративный документ** — внутренний документ компании для ознакомления.

## **Уведомления**

**Уведомление**	— сообщение пользователю о событии в системе.

**Push-уведомление** —	уведомление в мобильное приложение.

**Канал отправки** — способ доставки уведомления (push, СМС, email).

**Триггер уведомлений**	 — событие, вызывающее отправку уведомления.

**Кастомное уведомление** — уведомление с индивидуальной настройкой.

**Дефолтное уведомление** — стандартное уведомление с предопределёнными параметрами.

## **Виджеты и интерфейс**

**Виджет** — функциональный блок на главной странице.

**Логотип** — изображение компании; поддерживаются полная и компактная версии.

## **Интеграция с 1С**

**1С ЗУП** — 1С: Зарплата и Управление Персоналом.

**1С Рабочее место кадровика** — интерфейс кадрового специалиста в 1С.

**Модуль 1С** — компонент VK HR Tek на стороне 1С для обмена данными.

**Расширение 1С** — дополнение к типовой конфигурации 1С для интеграции с VK HR Tek.
