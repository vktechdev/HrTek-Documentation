## **Создание пополняемой целевой аудитории**

Тип ЦА определяет способ формирования сотрудников, которые входят в состав ЦА, а также способ его обновления. 

Состав пополняемой ЦА определяется настроенными фильтрами **Юрлицо**, **Тип оргструктуры**, **Подразделение**, **Должность** в блоке **Группа сотрудников**. Если выбрать пополняемый тип, то список сотрудников будет автоматически пополняться новыми сотрудниками. 

На странице создания целевой аудитории заполните следующие поля:

* **Название целевой аудитории**\*. Максимальное количество вводимых символов — 120. Если вы ввели название, которое совпало с ранее созданной аудиторией, то система не разрешит сохранить аудиторию с таким названием — придумайте другое название.   
* **Тип аудитории**. Выберите вариант *Пополняемый*.  
* **Юрлицо**\*. Выберите название компании из списка, если в аккаунте доступно несколько компаний.  
* **Тип оргструктуры**. Выберите один из вариантов: *Все*, *Юридическая*, *Управленческая*.    
* **Подразделение**\*. Поле доступно, если выбран тип оргструктуры *Юридическая* или *Управленческая*. Выберите название подразделения. В ЦА будут добавлены сотрудники из выбранного подразделения.   
* **Должность**. Выберите одну или несколько названий должностей из списка. В ЦА будут добавлены сотрудники с указанной должностью.

При необходимости добавьте еще одну группу сотрудников.    

Нажмите кнопку **Создать**.

![](./assets/Creating_TA.png)

## **Создание непополняемой целевой аудитории**

Состав непополняемой ЦА определяется вручную — через выбор сотрудников. При выборе непополняемого типа список сотрудников будет фиксированный, но может уменьшаться из-за увольнений.

В дальнейшем добавить сотрудников в состав ЦА можно только через редактирование ЦА. 

На странице создания целевой аудитории заполните следующие поля:

* **Название целевой аудитории**\*. Максимальное количество вводимых символов — 120. Если вы ввели название, которое совпало с ранее созданной аудиторией, то система не разрешит сохранить аудиторию с таким названием — придумайте другое название.   
* **Тип аудитории**. Выберите вариант *Непополняемый*.  
* **Юрлицо**\*. Выберите название компании из списка, если в аккаунте доступно несколько компаний.  
* **Сотрудники**\*. Выберите ФИО одного или нескольких сотрудников из списка.

При необходимости добавьте еще одну группу сотрудников.   

Нажмите кнопку **Создать**.

![](./assets/Creating_TA3.png)

## **Состав и предпросмотр целевой аудитории** 

Автоматическое обновление состава ЦА происходит каждый день в 12:00 и 23:59 с учетом настроек (тип ЦА, аккаунт, фильтры) и текущего состава. 

Чтобы открыть список сотрудников, входящих в ЦА, нажмите кнопку **Посмотреть состав** в блоке **Состав ЦА**.

![](./assets/Creating_TA2.png)

Для непополняемой ЦА в информации по группам, влияющим на выдачу, отображается только юрлицо. 

![](./assets/detailed.png)

Для пополняемой ЦА по сотрудникам доступна следующая информация:

* ФИО,  
* Юрлицо,  
* Подразделение,  
* Должность.

![](./assets/detailed1.png)
