Сервис позволяет разграничивать права доступа к новостям и опросам по целевым аудиториям.   

Целевые аудитории — набор сотрудников по определенным признакам, который позволяет более точечно разграничивать объекты социальных сервисов. В целевую аудиторию могут быть добавлены сотрудники из разных компаний аккаунта и разных подразделений компании.  

Доступ к разделу **Социальные сервисы → Целевые аудитории** имеют только пользователи с группами **Администратор модуля Портал** и **Менеджер сервиса Целевые аудитории**.
