Виджет доступен для размещения на главной странице только в тех компаниях/аккаунтах, в которых включен сервис «Опросы».

## Инструкция администратора

Для корректной настройки виджета пользователю должны быть добавлены роли «Администратор» и «Администратор главной страницы».

Для настройки расположения виджетов на главной странице:

* в рамках компании: перейдите в раздел **Настройки компании → Виджеты на главной странице** и нажмите кнопку **Настроить**;  
* в рамках аккаунта: перейдите в раздел **Настройки → Настройки аккаунта**, в блоке **Настройка интерфейса → Виджеты на главной странице** нажмите кнопку **Настроить**.

Для настройки виджета **Опросы**:

1. Перенесите виджет **Опросы** из блока **Виджеты для размещения** на основную область размещения виджетов.

![](./assets/widget-settings-empty-15.png)

2. Нажмите на виджет **Опросы** и выберите размер виджета и значения для настроек доступности:  
* Разрешить сотрудникам отключать виджет.  
* Разрешить сотрудникам настраивать виджет.  
3. Сохраните изменения.

![](./assets/widget-settings-empty-16.png)

## Инструкция сотрудника

Если Администратор КЭДО включил возможность настраивать виджет **Опросы** сотрудникам, то:

1. Перейдите в раздел **Виджеты главного экрана**. Для этого нажмите кнопку ![](./assets/square_4_plus_outline_24.png "inline").

![](./assets/unnamed49.png)

2. Если для сотрудников была включена настройка отключать виджет, то переведите переключатель в активное или неактивное состояние.  
3. Если для сотрудников была включена возможность настраивать виджет, то нажмите кнопку **Настроить**.

![](./assets/Settings_1.png)

4. На странице настройки виджета укажите название виджета (не более 50 символов) и сохраните.

![](./assets/Page_Personal_links_widget_4.png)

5. Сохраните настройки виджета.

![](./assets/Main_Saas_Page_Company_2.png)
