## Кастомные уведомления

Компания совместно с менеджером ВК может настроить кастомные уведомления. Для этого направьте заполненный файл [Параметры настройки уведомлений](./assets/Settings_notifications.xlsx "download") на адрес поддержки support@hrtek.ru.

Для заполнения файла:
1. Вносите данные в поля, выделенные только зеленым цветом.
2. Укажите название своего юрлица.
3. Выделите цветом необходимые настройки в таблицах для сотрудника, представителя компании, руководителя, корпоративных документов.
4. Для выбранной настройки укажите необходимые данные в зеленой ячейке.
5. Для отправки каждого вида уведомлений можно выбрать один или два канала связи — Email и Telegram. По умолчанию в таблице выделены оба варианта. 
6. Укажите время для рассылки уведомлений (будние дни или будни с выходными).
7. Перечислите бизнес-процессы, по которым будут приходить уведомления. 
8. Сохраните файл.

## **Учёт рабочих графиков в дедлайнах и уведомлениях**

<info>

В веб-сервис VK HR Tek из 1С передаются графики работы сотрудников. Для подключения импорта графиков работы обратитесь в [поддержку VK HR Tek](/ru/hr/support/contact_channels)

</info>

Все дедлайны и уведомления рассчитываются с учётом индивидуального рабочего графика сотрудника.

**Что это значит:**

- Дата завершения этапа теперь выпадает на **рабочий день исполнителя**, а не на календарный.
- Уведомления приходят:
  - за N **рабочих**, а не календарных дней до события;
  - или через N рабочих дней после события.
- Учитывается график:
  - получателя уведомления;
  - или сотрудника, о котором идет речь в уведомлении.

Больше никаких писем «в выходной» или некорректных сроков.

## **Push-уведомления в мобильном приложении**

Пользователи могут получать push-уведомления в мобильном приложении VK HR Tek. 

Для дефолтных уведомлений с каналом отправки СМС будет работать следующая логика:

* если пуш-уведомления включены, тогда пуш-уведомление придет пользователю:   
  * если пуш в течение 10 мин не будет прочитан, следом придет СМС,  
  * если пуш будет прочитан, то СМС не придет.  
* если пуш-уведомления не включены или у пользователя нет мобильного приложения, то сразу придет СМС. 

Также канал пуш-уведомлений появился для ряда кастомных уведомлений. По умолчанию пуш-уведомления будут выключены.  

<info>

Чтобы включить пуш-уведомления для кастомных уведомлений, обратитесь в поддержку VK HR Tek. В обращении перечислите типы уведомлений, для которых доступно подключение пуш-уведомлений (см. файл [Параметры настройки уведомлений](./assets/Settings_notifications.xlsx "download"))  

</info>

## Отправка одноразовых кодов подтверждения в мессенджер MAX

Начиная с версии 2026.04 приоритетным каналом отправки одноразовых кодов подтверждения для входа в сервис VK HR Tek станет меccенджер MAX:
* если у пользователя есть MAX, то одноразовый код придет в мессенджер (чат-бот «Коды подтверждения»), не по СМС;   
* если у пользователя есть MAX, но пуш-уведомление не доставлено/не открыто, то одноразовый код придет в СМС через одну минуту после неуспешной доставки в MAX;  
* если у пользователя нет MAX, тогда одноразовый код будет сразу отправлен по СМС.

<warn> 
Не путать с одноразовыми кодами от УЦ Контур при подписании УНЭП (коды от УЦ Контур продолжат приходить в СМС)
</warn>  

<info>
Бот MAX «Коды подтверждения» — официальный чат-бот в мессенджере MAX, через который приходят коды подтверждения от разных сервисов (например, для входа на «Госуслуги», для входа в VK HR Tek и др.)  
</info>
