Уведомления, которые получают пользователи от сервиса VK HR Tek, отправляются только с электронных адресов:
- **no-reply@vkdoc.mail.ru**
- **robot@mlrmr.com**

Если уведомления от сервиса не приходят, попробуйте добавить эти адреса в список доверенных (белый список). 

Уведомления сервиса VK HR Tek могут поступать разным группам пользователей: сотрудникам, кандидатам, представителям компании, руководителям.

## Кастомные уведомления

Компания совместно с менеджером ВК может настроить дополнительные уведомления. Для настройки дополнительных уведомлений направьте заполненный файл [Параметры настройки уведомлений](./assets/Settings_notifications.xlsx "download") на электронный адрес поддержки support@hrtek.ru.

Для заполнения файла:
1. Внесите данные только в поля, выделенные зеленым цветом.
2. Укажите название своего юрлица.
3. Выделите цветом необходимые настройки в таблицах для сотрудника, руководителя, представителя компании, создателя, ассистента.
4. Для выбранной настройки укажите необходимые данные в зеленой ячейке.
5. Для отправки каждого вида уведомлений можно выбрать каналы связи. 
6. Укажите время для рассылки уведомлений.
7. Перечислите бизнес-процессы, по которым будут приходить уведомления. 
8. Сохраните файл.

## **Учёт рабочих графиков в дедлайнах и уведомлениях**

<info>

В веб-сервис VK HR Tek из 1С передаются графики работы сотрудников. Для подключения импорта графиков работы обратитесь в [поддержку VK HR Tek](/ru/hr/support/contact_channels)

</info>

Все дедлайны и уведомления рассчитываются с учётом индивидуального рабочего графика сотрудника.

**Что это значит**:

- Дата завершения этапа выпадает на **рабочий день исполнителя**, а не на календарный.
- Уведомления приходят:
  - за N **рабочих**, а не календарных дней до события;
  - или через N рабочих дней после события.
- Учитывается график:
  - получателя уведомления;
  - или сотрудника, о котором идёт речь в уведомлении.

Больше никаких писем «в выходной» или некорректных сроков.

## **Push-уведомления в мобильном приложении**

Пользователи могут получать push-уведомления в мобильном приложении VK HR Tek. 

Для дефолтных уведомлений с каналом отправки СМС будет работать следующая логика:

* если push-уведомления включены, тогда push-уведомление придёт пользователю:   
  * если push в течение 10 мин не будет прочитан, следом придёт СМС,  
  * если push будет прочитан, то СМС не придёт.  
* если push-уведомления не включены или у пользователя нет мобильного приложения, то сразу придёт СМС. 

Также канал push-уведомлений появился для ряда кастомных уведомлений. По умолчанию push-уведомления будут выключены.  

<info>

Чтобы включить push-уведомления для кастомных уведомлений, обратитесь в поддержку VK HR Tek. В обращении перечислите типы уведомлений, для которых доступно подключение push-уведомлений (см. файл [Параметры настройки уведомлений](./assets/Settings_notifications.xlsx "download"))  

</info>

## Отправка одноразовых кодов подтверждения в мессенджер MAX

<info>

Коды подтверждения от УЦ Контур для подписания документов и ознакомления с ЛНА в VK HR Tek могут приходить в MAX (https://vk.company/ru/press/releases/12305)

</info>

Начиная с версии 2026.04 приоритетным каналом отправки одноразовых кодов подтверждения для входа в сервис VK HR Tek станет меccенджер MAX:
* если у пользователя есть MAX, то одноразовый код придёт в мессенджер (чат-бот «Коды подтверждения»), не по СМС;   
* если у пользователя есть MAX, но push-уведомление не доставлено/не открыто, то одноразовый код придёт в СМС через одну минуту после неуспешной доставки в MAX;  
* если у пользователя нет MAX, тогда одноразовый код будет сразу отправлен по СМС.


<info>
Бот MAX «Коды подтверждения» — официальный чат-бот в мессенджере MAX, через который приходят коды подтверждения от разных сервисов (например, для входа на «Госуслуги», для входа в VK HR Tek и др.)  
</info>
