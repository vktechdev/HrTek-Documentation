## Настройка соответствия документов 1С и КЭДО

Для корректного создания «Приказа о предоставлении дней отдыха в связи со сдачей крови» из документа 1С «Отсутствие с сохранением оплаты» должно быть настроено соответствие документов и реквизитов.

В разделе **КЭДО → Начальная настройка → Соответствие документов** сопоставьте документ 1С «Отсутствие с сохранением оплаты» с документом КЭДО «Заявление о предоставлении дня отдыха за сдачу крови и ее компонентов».

![](./assets/Screenshot_354.png)

Чтобы сопоставить реквизиты 1С атрибутам КЭДО, нажмите кнопку **Соответствие реквизитов**.

В таблице слева для нужных реквизитов основной части документа выберите атрибуты из заявки КЭДО. Важно, чтобы тип данных реквизита соответствовал типу данных атрибута, иначе заполнение поля в документе не сработает. Для реквизитов **Вид времени**, **Дата начала**, **Дата окончания**, **Дата начала периода сохранения среднего заработка** это будут атрибуты **Вид времени**, **День отсутствия**, **День отсутствия**, **День отсутствия**.

![](./assets/rec.png)

## Этап 4. Проверка заявления Отделом кадров
