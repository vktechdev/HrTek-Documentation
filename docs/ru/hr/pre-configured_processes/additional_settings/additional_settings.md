Коробочные бизнес-процессы возможно донастраивать под запросы клиента. Такие донастройки являются платными. Для выполнения донастроек обратитесь в [поддержку VK HR Tek](/ru/hr/support/contact_channels).

Донастройки бизнес-процессов можно отнести к двум типам: мелкие и крупные.

## Мелкие донастройки

- Копирование процесса из коробочного решения с изменением названия процесса (без изменения названий документов).
- Добавление настройки, позволяющей отправлять заявку на доработку на уже прошедшие этапы (возврат на доработку).
- Изменение текста в шаблоне заявления из коробочного решения (без изменения заполняемых атрибутов).
- Изменение типа оргструктуры в процессе (юридическая/управленческая).
- Изменение количества уровней согласования по оргструктуре.
- Добавление/изменение/удаление дедлайнов, валидаторов.
- Добавление/изменение/удаление атрибутов: текстовых/файловых/мультифайловых/дат.
- Добавление/изменение/удаление атрибута с опциями, взаимозависимых атрибутов.
- Добавление/изменение/удаление информационных элементов интерфейса (маски атрибутов/ограничение типов символов/информационные подсказки).
- Добавление/изменение/удаление этапа (с типом Проверка/Загрузка/Подписание).
- Добавление/изменение/удаление документа в процесс.
- Добавление/изменение/удаление ролей (Отдел кадров/Бухгалерия/Наблюдатель/Экономист/Функциональный руководитель и др.).
- Добавление/изменение/удаление настройки, позволяющей отменять заявку на этапе.
- Добавление/изменение/удаление в процесс группы сотрудника без изменения самого процесса.
- Добавление/изменение/удаление отображения доступных дней отпуска на каждом этапе.
- Добавление/изменение/удаление возможности массовой рассылки документа.
- Добавление/изменение/удаление возможности отказаться от подписания документов.
- Добавление/изменение/удаление функционала «согласование с поиском руководителей».
- Добавление/изменение/удаление функционала «без участия сотрудника».

## Крупные донастройки

- Добавление/изменение/удаление одной развилки (этапа с выбором одного из двух возможных последующих действий).
- Добавление/изменение/удаление дополнительного этапа с генерацией PDF-документа.
- Копирование процесса из коробочного решения с изменением названий документов в процессе и названия процесса.
- Добавление/изменение/удаление шаблона.
- Добавление/изменение/удаление массового подписания документов.
- Добавление/изменение/удаление возможности выбора одного согласующего в процессе.
- Добавление/изменение/удаление параллельного подписания/согласования (два параллельных этапа).
- Добавление/изменение/удаление функционала «связанные заявки».
- Добавление/изменение/удаление функционала «создание заявки сотрудником на другого сотрудника».
