В сервисе «Новости» появились две специализированные роли:

- **Менеджер сервиса Новости** — этот пользователь отвечает за настройку доступа к новостям в разделе **Социальные сервисы → Новости**. Он может назначать других сотрудников авторами или менеджерами сервиса «Новости», не имея полных прав «Администратора модуля Портал».

- **Автор новостей** — сотрудник, который может создавать и публиковать новости в разделе **Социальные сервисы → Новости**. Роль подходит для руководителей отделов, PR-менеджеров или HR-специалистов, ответственных за информирование коллектива.

Назначение всех вышеперечисленных ролей пользователей и управление правами доступа к сервису «Новости» осуществляется в разделе **Социальные сервисы →** **Администраторы**.

Доступ к разделу имеют пользователи с ролями «Администратор модуля Портал» и «Менеджер сервиса Новости».

## Выдача прав доступа

Пользователи с ролями «Администратор модуля Портал» и «Менеджер сервиса Новости» могут выдавать права только тем аккаунтам и компаниям, к которым у этих пользователей есть доступ.  
Выполните действия:

1. Перейдите в раздел **Социальные сервисы →** **Администраторы**.  
2. Нажмите кнопку **Выдать права доступа**.

![](./assets/admin1.png)

### Назначение прав доступа на юрлица

На форме **Выдача прав доступа** выполните действия:

1. Выберите тип социального сервиса **Новости** при наличии доступа к более чем одному сервису.  
2. Выберите наименование аккаунта, если у вашего пользователя есть доступ к нескольким аккаунтам.  
3. В настройке **Назначить права** выберите вариант **На юрлица аккаунта**. Права будут применены только к выбранным юрлицам.    
4. Выберите наименование юрлица, если у вашего пользователя есть доступ к нескольким компаниям.  
5. В поле **Администратор** выберите ФИО одного или нескольких пользователей.  
6. В поле **Права доступа** выберите одну или несколько ролей для выбранных пользователей.  
7. При необходимости добавьте ещё один блок с правами доступа.   
8. Сохраните внесённые данные.

![](./assets/Accessrights_Add.png)

<br>

![](./assets/Accessrights_Addnew_1.png)

### Назначение прав доступа на весь аккаунт

На форме **Выдача прав доступа** выполните действия:

1. Выберите тип социального сервиса **Новости** при наличии доступа к более чем одному сервису.  
2. Выберите наименование аккаунта, если у вашего пользователя есть доступ к нескольким аккаунтам.  
3. В настройке **Назначить права** выберите вариант **На весь аккаунт**. Права будут применены на текущие и новые юрлица аккаунта.    
4. В поле **Администратор** выберите ФИО одного или нескольких пользователей.   
5. В поле **Права доступа** выберите одну или несколько ролей для выбранных пользователей.  
6. При необходимости добавьте ещё один блок с правами доступа.   
7. Сохраните внесённые данные.

![](./assets/Accessrights_Add1.png)

## Редактирование прав доступа

Чтобы отредактировать уже назначенные права доступа, вернитесь к списку администраторов и напротив нужного администратора выберите действие **Редактировать права доступа**.

![](./assets/Massapproving-12.png)

<br>

Чтобы изменить список компаний, к которым у выбранного администратора будет доступ, выполните действия:

1. На форме **Редактирование прав доступа** для настройки **Назначить права** оставьте вариант **На юрлица аккаунта**.   
2. В поле **Юрлицо** добавьте или удалите наименование компании.  
3. Сохраните изменения.

![](./assets/Popup2.png)

<br>

Чтобы расширить права доступа на весь аккаунт, для настройки **Назначить права** выберите вариант **На весь аккаунт** и сохраните изменение. 

![](./assets/Popup3.png)

<br>

Редактирование прав доступа будет запрещено в случаях:

* если у администратора есть доступ только к одному юрлицу аккаунта,  
* если у администратора есть права доступа на весь аккаунт.  
    

Чтобы изменить права доступа для выбранного администратора, сначала удалите права доступа у этого администратора, а затем добавьте права доступа с новыми настройками. 

![](./assets/Massapproving-11.png)

## Удаление прав доступа

Чтобы удалить ранее назначенные права доступа, вернитесь к списку администраторов и напротив нужного администратора выберите действие **Удалить права доступа**.  

![](./assets/Massapproving-13.png)

<br>

Подтвердите удаление прав доступа у выбранного администратора.

## Применение фильтров

Для вашего удобства предусмотрена настройка отображения списка администраторов. Нажмите на кнопку **Фильтры**. Откроются поля для редактирования фильтра с выбором значений из выпадающего списка.

Доступны следующие фильтры:

* **По администратору** — выбор одного или нескольких значений из предложенного списка с возможностью текстового поиска по ФИО.  
* **По правам доступа** — выбор одного или нескольких значений из предложенного списка с возможностью текстового поиска по названию роли.  
* **По юрлицу** — в случае если у вашего пользователя есть доступ к нескольким компаниям, то в этом фильтре можно выбрать все юрлица или одно из них.
